# To Do App
🎉 Welcome to **to_do_app**!

## Overview
This project was created on May 15 to help me learn the basics of sqlite operations with python, 
it also uses tkinter to help give it a more user-friendly interface
 
## Attributes
- ✅ Functional for most circumstances
- ✅ GUI interface
- ✅ sqlite3 database

## Compatibility
- Platforms:
  - ✅ Windows
  - ✅ macOS
  - ✅ Linux

- Python Versions:
  - ✅ Python 3.9+

## Requisites
- Python 3

## Install

Install:
```shell
git clone https://github.com/29miaoet/to_do_app.git
cd to_do_app
python to_do_app.py # Powershell
python3 to_do_app.py # Shell
```
Some examples are included in data.db, feel free to experiment with them.
